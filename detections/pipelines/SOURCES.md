to JSON; identifiers rewritten to safe markers (namespace, pod, node, project and
cluster names to `trr9007-` names; the caller IP addresses to RFC 5737 `192.0.2.3` and
`192.0.2.7`; UIDs and insert IDs to `00000000-0000-4000-8000-00000000000N`). The
`native` Event in each anchor is written by this repository; it is not part of the
source. It follows what the API server writes: the pod create's `objectRef` has no name,
because the request has only `metadata.generateName` (see the Kubernetes row below).
